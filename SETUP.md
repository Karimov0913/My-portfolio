# Setup Instructions

## Quick Start

1. **Open the website**: Simply open `index.html` in any modern browser
2. **Add assets**:
   - Place your profile photo at `assets/images/profile.jpg` (400x400px recommended)
   - Place your resume PDF at `files/resume.pdf`

## Data Customization

All content can be customized in `js/animations.js`:

- **projects** array: Update project details
- **experiences** array: Update work history
- **posts** array: Update blog posts

## Color Scheme

The dark theme uses these CSS variables (in `css/main.css`):

```css
--bg-primary: #0a0a0a;
--bg-secondary: #1a1a1a;
--bg-card: #1e1e1e;
--text-primary: #e0e0e0;
--text-secondary: #a0a0a0;
--accent: #3b82f6;
```
